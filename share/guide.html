The one habit

Tell Claude the end goal.

Most people ask Claude many small questions. Describe the finished product first. Then ask if it is possible, how to achieve it, and which tools you need.

Small questions

"What is a good quiz tool?" then "How do I make a timer?" then "Can it show answers?"

You do the planning. Claude only answers each piece.

The end goal

"I want a quiz page where my Sec 1 students write their working before they choose an answer, and I see every answer. Is this possible? How can we achieve it?"

Claude plans the whole thing and builds it.

Say four things

  1. The finished productWhat the student sees and does, and what you see.
  2. Who it is forThe level, the subject, and the learning process you want technology to enhance (your KAT).
  3. Is this possible?Let Claude tell you what can and cannot be done before it starts.
  4. How, and with which tools?Ask how to achieve it, and whether other tools should be combined with Claude.

Your first build

Combine two tools you already like.

You do not need a whole hub. Pick one feature you like in one tool and one feature you like in another, and ask Claude to put them on one page.

  1. Choose your KATWhich learning process should technology enhance in one lesson next term?
  2. Name two toolsFor example Kahoot and OneNote. Say what you like about each, and what the problem is.
  3. Write the promptUse the template below. Start with the end goal.
  4. Try what Claude buildsUse it as a student would. Tell Claude what is wrong in plain words.
  5. Explain it in one sentence"I combined tool A and tool B so that my students can do this."

Prompts to copy

Fill in the blanks, or start from a sample.

The template

I want [the finished product]. It is for [level and subject], and the KAT is [your KAT]. It should work like [tool A] and [tool B] together. Is this possible? How can we achieve it? Which tools do we need?

Kahoot + OneNote

I want a quiz page where my Sec 1 Science students write their working before they choose an answer, and I see every answer. The KAT is Support Assessment for Learning. It should work like Kahoot and OneNote together. Is this possible? How can we achieve it? Which tools do we need?

PhET + Kahoot

I want a page where my Sec 3 Physics students change the angle of a light ray and score points for hitting a target under water. The KAT is Foster Conceptual Change. It should work like PhET and Kahoot together. Is this possible? How can we achieve it? Which tools do we need?

Padlet + exit ticket

I want a page where each Sec 2 student posts one answer before leaving, and similar answers are grouped for me. The KAT is Facilitate Learning Together. It should work like Padlet and an exit ticket together. Is this possible? How can we achieve it? Which tools do we need?

Ask about other tools

Can this be done with Claude alone? If not, tell me which other tools would help, such as Google Apps Script, GitHub, Canva or an image or video tool, what each one would do, and the steps for someone who has never used them.

Tips and tricks

Habits that save the most time.

Let Claude ask you questions

End your prompt with a request for questions. You will get a better first version.

"Before you build, ask me anything you need to know."

Show an example

Upload a worksheet, a slide or a screenshot of a tool you like. Claude copies the style far better from an example than from a description.

"Make it look and feel like this."

Ask for one sample first

For anything big, such as ten worksheets, ask for one. Fix it, then ask for the rest in the same style.

"Do one first and wait for me."

Describe what you see

You do not need technical words. Say what happened and what you expected.

"When I press Check, nothing happens. It should show the answer."

Change one thing at a time

Small, clear requests are easier to check than a long list.

"Keep everything else. Only make the timer bigger."

Ask Claude to test it

Ask it to try the page as a student and to tell you what it could not check.

"Test this as a student and list what you did not test."

Ask for the reason

If Claude makes a choice you do not understand, ask why. It should explain in plain words.

"Why did you do it this way? Is there a simpler way?"

Save your rules once

If you always want the same style, tell Claude to remember it, or keep your instructions in a project.

"From now on, write for Sec 1 students in short sentences."

Start a new chat when it drifts

Very long chats get confused. Ask for a summary, then paste it into a new chat.

"Summarise what we built and what is left, so I can continue in a new chat."

Check the content yourself

Claude can be wrong about facts, answers and marks. You are the subject teacher. Read before students see it.

"Show me the answers so I can check them."

Words you will see

A short glossary.

WordWhat it means for you
PromptThe message you type to Claude.
ArtifactA page Claude builds that opens beside the chat, such as a quiz, a game or a simulation. It has its own link.
ProjectA folder that keeps your chats, files and instructions for one piece of work together.
ConnectorA link between Claude and another app you use, such as Google Drive or Canva, so Claude can work with it.
SkillA saved set of instructions for a task you repeat, such as making a worksheet in your school's format.
KATKey Applications of Technology from the MOE Guide to e-Pedagogy. It names the learning process that technology enhances.

When it goes wrong

Quick fixes.

What happenedWhat to say or do
It built the wrong thingDescribe the finished product again, from the student's point of view. Say what should stay and what should change.
A button does nothingTell Claude which button, what you pressed before it, and what you expected.
It looks wrong on an iPadSay which device and send a screenshot. Ask Claude to make it work on that screen size.
The answers are wrongGive Claude the correct answer and the reason. Ask it to check the others in the same way.
It is too complicatedAsk for the simplest version that does one job. Add features later.
Claude says it cannotAsk what the closest possible version is, and which other tool could do the missing part.

Student data

Keep students safe.

  • Do not type student names, NRIC numbers or grades into a prompt.
  • Do not upload class lists, marked scripts with names, or photos of students.
  • Use made-up names such as Test Student when you need an example.
  • Keep names off the projector. Show totals to the class and keep names on your own screen.
  • Follow the school's and MOE's rules on which tools may hold student data. If you are unsure, ask before you use it with a class.

Sharing what you built

Getting it to your students.

  1. Open the page Claude builtIt is private until you choose to share it.
  2. Use the Share option on the pageCopy the link it gives you.
  3. Try the link as a studentOpen it on another device where you are not signed in, before the lesson.
  4. Give students the linkPost it where your class already looks, or show a QR code.

If you need students' answers to be saved and seen by you later, tell Claude that at the start. It changes how the page must be built.

How Mr Cedric's hub fits together

GitHub holds the pages: lesson slides, games and the hub's screens.

Google Apps Script is the engine: sign-in, handing in and marking.

Google Sheets keeps the records. Google Drive keeps the worksheet files.

Before you host anything

A GitHub page is public. Anyone with the address can open it.

Never put student names, NRIC numbers or grades in a public page.

Check your school's rules before students sign in to anything you build.

A. Put a page on GitHub Pages

  1. Get the page as one fileAsk Claude: "Give me this as a single HTML file that I can host." Download the file.
  2. Make a free GitHub accountGo to github.com and sign up.
  3. Create a new repositoryA repository is a folder for one project. Give it a short name such as my-lessons, and choose Public. On a free account, GitHub Pages only works with a public repository.
  4. Upload your fileIn the repository, choose Add file, then Upload files. Drag your HTML file in and press Commit changes.
  5. Turn on PagesOpen Settings, then Pages. Under Build and deployment, set Source to Deploy from a branch, and choose the main branch.
  6. Open your addressWait a few minutes. It can take up to ten. Your page is at yourname.github.io/my-lessons/yourfile.html. A file named index.html opens at yourname.github.io/my-lessons.
  7. To change the page laterUpload a file with the same name again. The address stays the same.
Ask Claude to walk you through it

I want to put this page online with GitHub Pages. I have never used GitHub. Walk me through it one step at a time, and wait for me to say done after each step. If I send a screenshot, tell me where to click.

B. Save answers with Google Apps Script

You only need this when the page must remember things, such as each student's answer.

  1. Say it in your end goalTell Claude that each student's answer must be saved to a Google Sheet, and that you want to use Google Apps Script. Ask for the code and the setup steps.
  2. Make a Google SheetThis is where the records will go. Open Extensions, then Apps Script.
  3. Paste the codePaste what Claude gives you into the files it names, and save.
  4. Deploy it as a web appChoose Deploy, then New deployment, and pick Web app as the type. Fill in who the app runs as and who can open it, then press Deploy. Google will ask you to approve the permissions.
  5. Copy the web app addressIt ends in /exec. This is the link you give students.
  6. After every changeDeploy a new version, or students will keep seeing the old one. Ask Claude to remind you how each time.
Ask Claude to set it up with you

I want this page to save each student's answer in a Google Sheet using Google Apps Script. I have never used Apps Script. Give me the code, then walk me through the setup one step at a time, and wait for me after each step. Use made-up names in any example.

C. Keep files in Google Drive

  1. Make one folder for the projectPut your worksheet PDFs in it.
  2. Tell Claude what the folder is forFor example, "worksheets are in this folder, and handed-in work should be saved in a second folder". Claude writes the Apps Script to do it.
  3. Keep the folder privateLet your app decide who sees what. Do not set a folder of student work to anyone with the link.

Menu names on GitHub and Google change from time to time. If a button is not where this page says, send Claude a screenshot and ask where to click.
