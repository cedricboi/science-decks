Step 6 of 7 · going further

Save answers with Google Apps Script.

A page from Claude forgets everything when it is closed. If you want to see each student's answer afterwards, something has to keep it. Google Apps Script does that, and it comes free with your Google account.

What it is, in plain words

The pageWhat students seeThe quiz or activity Claude built.
Apps ScriptThe engineA few lines of code that live inside a Google Sheet. It receives each answer.
Google SheetThe record bookOne row for every answer, with the time.
Google DriveThe filing cabinetFiles such as worksheet PDFs, if you need them.

This is how my own hub works. Apps Script runs the sign-in, the handing in and the marking, and Google Sheets keeps the records.

Ask Claude to set it up with you

What the steps look like

  1. Make a Google Sheet. This is where the records go. Open Extensions, then Apps Script.
  2. Paste the code. Claude gives you the code and names the files it goes into. Save.
  3. Deploy it as a web app. Choose Deploy, then New deployment, and pick Web app. Fill in who the app runs as and who can open it, then press Deploy. Google asks you to approve the permissions.
  4. Copy the web app address. It ends in /exec. This is the link you give students.
  5. After every change, deploy a new version. Otherwise students keep seeing the old one.
What the code looks like

You do not need to write this. It is here so that it does not look mysterious when Claude gives you something similar. In this small example the page lives inside Apps Script too. The first part opens the page. The second part adds one row to the Sheet.

function doGet() {
  return HtmlService.createHtmlOutputFromFile('Index');
}

function saveAnswer(seat, answer) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sheet.appendRow([new Date(), seat, answer]);
  return 'Saved';
}
Before students use it. Use seat numbers or made-up names in your first test. Check your school's rules before students sign in to anything you build. Keep the Sheet private to you.

Step 7 of 7 · going further

Give it a permanent address with GitHub.

GitHub is a free place to keep files online. It has two uses for a teacher. It keeps every version of your page, and its Pages feature turns a file into a public web page. This page you are reading is on GitHub Pages.

The steps

  1. Get the page as one file. Ask Claude for a single HTML file that you can host, and download it.
  2. Make a free account at github.com.
  3. Create a new repository. A repository is a folder for one project. Give it a short name such as my-lessons, and choose Public.
  4. Upload your file. Choose Add file, then Upload files. Drag the file in and press Commit changes.
  5. Turn on Pages. Open Settings, then Pages. Set Source to Deploy from a branch, choose the main branch and press Save.
  6. Open your address. Wait a few minutes. Your page is at yourname.github.io/my-lessons/yourfile.html.

To change the page later, upload a file with the same name again. The address stays the same.

Ask Claude to walk you through it

I want to put this page online with GitHub Pages. I have never used GitHub. First give me the page as a single HTML file that I can host. Then walk me through it one step at a time, and wait for me to say done after each step. If I send a screenshot, tell me where to click.
A GitHub page is public. Anyone with the address can open it. Never put student names, NRIC numbers or grades in a public page.
